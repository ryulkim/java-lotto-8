# 로또 문제

## 기능 구현 목록

### 입력

- [X] 금액 입력
- [X] 로또 숫자 입력
- [X] 보너스 번호 입력

### 출력

- [X] 구입 금액 입력 문구 작성
- [X] 구매 개수 문구 작성
- [X] 당첨 번호 입력 문구 작성
- [X] 보너스 번호 입력 문구 작성
- [X] 구매 문구 출력
- [X] 당첨 통계 문구 작성
- [X] 수익률 출력 문구 작성
- [X] 에러 문구 출력

### 로또

- [X] 숫자 랜덤으로 6개 생성
- [X] 숫자 오름차순 정렬
- [X] 구매 개수 계산
- [X] 당첨 확인
- [X] 금액 계산
- [X] 수익률 계산

### 예외 처리

#### 금액

- [X] 입력 금액 범위 최대 Integer 범위 안 넘도록 처리
- [X] 금액 최대 1000이하일 경우 예외
- [X] 금액 1000으로 나누어떨어지지 않을 경우 예외 처리
- [X] 금액이 숫자가 아닐 경우

#### 당첨 번호

- [X] 1~45 범위가 아닌 경우 예외 처리
- [X] 문자일 경우 예외 처리
- [X] 숫자 쉼표 사이의 공백 허용 처리
- [X] 번호가 6개보다 많거나 적을 경우 예외 처리
- [X] 번호가 중복될 경우 예외 처리

#### 보너스 번호

- [X] 1~45 범위가 아닌 경우 예외 처리
- [X] 문자일 경우 예외 처리
- [X] 번호가 1개보다 많거나 적을 경우 예외 처리
- [X] 당첨 번호 중에 하나일 경우 예외 처리

#### 로또

- [X] 뽑은 숫자들이 중복되지 않는지 확인

#### 예외 처리

- [X] "[ERROR]"로 시작하는 에러 메시지를 출력
- [X] 에러 부분부터 입력을 다시 받기

### 주의 사항

- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다. (메소드 분리할 것)
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
- 테스트 코드를 쓴다.
- else, switch/case 예약어를 쓰지 않는다 (if 안에 return 방식을 쓴다.)
- Enum을 적용해 구현한다.
- Randoms 라이브러리를 사용한다.
- 제공된 Lotto 클래스를 사용해 구현한다. (numbers 이외의 필드는 추가할 수 없다.)
